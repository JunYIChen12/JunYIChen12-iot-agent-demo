# v0.1.0 Release Notes

Date: 2026-06-09

## Summary

`v0.1.0` is the first runnable baseline for the personal IoT Agent Demo. It proves the core chain:

```text
simulated device -> MQTT broker -> data worker -> database -> rule alarm -> dashboard -> AI assistant
```

## What Can Be Demonstrated

1. Start the stack with Docker Compose.
2. Watch the simulator publish telemetry every 5 seconds.
3. See `demo-device-001` become online.
4. View latest temperature, humidity, and battery data.
5. Trigger temperature alarms above `50`.
6. Ask the AI assistant about alarms, thing models, topic format, or device status.

## URLs

- Frontend: http://localhost:5173
- Backend API docs: http://localhost:8000/docs
- EMQX dashboard: http://localhost:18083

EMQX default account:

```text
username: admin
password: public
```

## Baseline Architecture

- Backend: FastAPI
- Broker: EMQX Community
- Data worker: Python MQTT subscriber
- Simulator: Python MQTT publisher
- Database: PostgreSQL
- Cache: Redis
- Frontend: Vue 3, Element Plus, ECharts

## Next Version Candidates

- `v0.2.0`: product/device CRUD pages and broker auth enforcement.
- `v0.3.0`: device command downlink and basic device shadow.
- `v0.4.0`: real LLM Agent with safe tool calling.
- `v0.5.0`: dedicated time-series database and Grafana integration.
