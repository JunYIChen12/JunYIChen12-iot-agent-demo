# v0.2.0-dev Release Notes

Date: 2026-06-09

This development version turns the first runnable dashboard into a small management console.

## What Changed

- Added UI modules for categories, products, devices, thing models, rules, logs, and AI assistant.
- Added create/list workflows for the core BladeX-style modeling chain.
- Updated the AI assistant so alarm explanations take priority over generic device status answers.
- Normalized seed data and alarm content formatting.
- Kept the stack fully free/open-source: FastAPI, Vue 3, Element Plus, ECharts, EMQX Community, PostgreSQL, Redis, and Docker Compose.

## Verified Chain

```text
create category -> create product -> configure thing model -> create device
-> simulator publishes MQTT telemetry -> backend shows device online
-> dashboard shows latest data and trend -> rule triggers alarm
-> AI explains why the device alarm fired
```

## Not Yet Final

- No formal `v0.2.0` tag yet.
- Manual property-post test page is still pending.
- MQTT broker-level credential enforcement is still pending.
